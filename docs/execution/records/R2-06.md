## Evidence brief before implementation

- Current behavior:
  - `GrailsProjectBuilder` and `GradleModel` extract `grailsVersion`, `groovyVersion`, and `targetCompatibility`.
  - `GormCapabilityAdapter` and other capability adapters check if GORM or Grails dependencies are present.
  - However, there is no formal, executable compatibility matrix defining tested combinations of Grails 7, Groovy 4, JDKs (17, 21), Gradle (8.10, 8.11, 8.12), artifact coordinates, and SHA-256 fingerprints.
  - There is no mechanism to evaluate a project's support level (`TESTED`, `EXPERIMENTAL`, `UNSUPPORTED`) or ensure new minor/patch versions of Grails 7 do not automatically become supported merely because the major version matches.
- Failure/missing behavior and smallest reproducer:
  - Missing compatibility registry: Projects cannot evaluate their combination of Grails version, Groovy version, JDK, and Gradle against verified combinations.
  - Unchecked version matching: An unverified Grails 7.9 project or arbitrary combination might be treated identically to a tested 7.0.0 combination rather than marked `EXPERIMENTAL`.
  - Incompatible version handling: Older Grails (< 7) or Groovy (< 4) or JDK (< 17) must be explicitly marked `UNSUPPORTED`.
  - Missing offline replay & matrix fixtures: No JSON manifest exists defining exact coordinates, fingerprints, and fixture provenance for offline verification.
- Relevant invariant IDs and affected owner/reader/cache boundaries:
  - `INV-DISC-001`: Scoped discovery — library facts are discovered from actual project/source-set dependency scope.
  - `INV-DISC-002`: Artifact facts separate from project membership; immutable artifact facts with coordinates and fingerprints.
  - `INV-DISC-003`: Results retain provenance (origin kind, artifact coordinates, signatures).
- Unknowns and how this task will resolve them:
  - Exact tested combinations: Defined as Grails 7.0.0-RC1 (matching `test-projects/grails-test-project`) + Groovy 4.0.23 + JDK 17/21 + Gradle 8.10/8.11/8.12, and Grails 7.0.0 + Groovy 4.0.24 + JDK 17/21 + Gradle 8.10/8.11/8.12.
  - Support levels: Enum `CompatibilityLevel` (`TESTED`, `EXPERIMENTAL`, `UNSUPPORTED`).
  - Offline replay: Tested using cached artifact fingerprints and project models without network calls.

  - Non-goals: Downloading arbitrary third-party Grails versions at runtime or supporting Grails 6 / older runtimes in 1.0 scope.
