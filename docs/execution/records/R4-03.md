## Evidence brief before implementation

- Current behavior:
  - GSP support in extension was limited to basic TextMate grammar syntax highlighting and partial server-side regex extraction.
  - Edits in embedded regions (HTML, CSS in `<style>`, JS in `<script>`, Groovy in `<% %>`, `<%= %>`, `${}`) were not routed through dedicated virtual documents with 1:1 coordinate masking.
  - Unmappable edits crossing region boundaries risked silent document corruption violating `INV-EDIT-001`.
  - Closing documents or removing workspaces left stale virtual document state in memory.
- Failure/missing behavior and smallest reproducer:
  - Typing inside `${...}` inside `<script>` or `<style>` blocks lacked Groovy language intelligence and TagLib completions.
  - Formatting or multi-line edits could bridge across Groovy and HTML regions, destroying embedded delimiters.
- Relevant invariant IDs and affected owner/reader/cache boundaries:
  - `INV-EDIT-001`: Unmappable edits must be rejected; coordinate translations must strictly preserve 1:1 offsets.
  - `INV-STATE-004/005`: Snapshots and virtual documents must maintain version synchronization and clean up upon document close.
  - `INV-PERF-002`: Bounded resource overhead; virtual documents evicted upon document close or workspace change.
- Unknowns and how this task resolved them:
  - Exact whitespace masking strategy: Non-target characters are replaced with space characters, preserving newline (`\n`, `\r`) structure and UTF-16 surrogate pairs verbatim so lines and character offsets in virtual documents match the host GSP document 1:1.

## Implementation decision

- Intended observable result; non-goals:
  - Implemented `GspRegionParser.ts`: Parses GSP documents into typed regions (`html`, `css`, `javascript`, `groovy`, `comment`, `directive`), handling nested interpolation within script/style blocks, CRLF, and unclosed malformed constructs.
  - Implemented `VirtualDocumentManager.ts`: Manages virtual documents under `gsp-virtual://` URI scheme, precomputes masked virtual content preserving exact line/column geometry, and purges records on `closeDocument` and `clear`.
  - Implemented `GspPositionMapper.ts`: Validates edit boundaries against active region boundaries; cleanly rejects cross-boundary edits (`mapEdit` returns null, `mapCompletionItem` drops unmappable additional edits) in accordance with `INV-EDIT-001`.
  - Implemented `GspEmbeddedLanguageService.ts`: Integrates TagLib completions (`g:each`, `g:if`, custom taglibs from `grails-app/taglib`), i18n completions, asset completions, hover, definition, and document formatting.
  - Created unit tests in `gspEmbeddedService.unit.test.ts` covering parser routing, nested blocks, astral characters, recovery, virtual doc masking, position mapper rejections, and lifecycle cleanup.
- Files/owners to change:
  - `client/src/services/gsp/GspRegionParser.ts`
  - `client/src/services/gsp/GspPositionMapper.ts`
  - `client/src/services/gsp/VirtualDocumentManager.ts`
  - `client/src/services/gsp/GspEmbeddedLanguageService.ts`
  - `client/src/test/gspEmbeddedService.unit.test.ts`

- Cache/resource impact, limits and invalidation:
