## Evidence brief before implementation

- Current behavior:
  - `DashboardService.ts` and `GrailsDashboard.ts`: Duplicate dashboard implementations existed. `GrailsDashboard.ts` rendered hardcoded fictional metrics ("24 Artifacts", "Grails 6.2.0", "94% Code Coverage", "1.2s LSP Indexing") and handled commands via raw string checks without validation. `DashboardService.ts` was in `ServiceRegistry` but uncalled. Neither implemented CSP (`Content-Security-Policy`), used unsafe inline `onclick` handlers, hardcoded light-mode colors in CSS violating dark/high-contrast themes, and lacked ARIA/keyboard accessibility.
  - `DependencyGraphService.ts`: Direct D3 force-directed graph rendering without CSP; ran continuous force animation ticks without respecting `prefers-reduced-motion`; lacked keyboard-navigable fallback or screen-reader tabular/list alternative; did not paginate or filter large dependency graphs (>300 nodes freeze UI); lacked clear origin disclosure (static approximation vs Gradle-resolved classpath) and stale/error state indicators.
  - `GormSqlPreviewService.ts`: Lacked CSP; rendered arbitrary SQL without explicit labeling of static DDL AST simulation vs live DB execution; did not support keyboard copying/focus or clear stale/disconnected states; lacked input validation on webview messages.
  - Service wiring & ownership (`INV-OWN-003/004`): `GrailsTaskCommands.ts` and `UICommands.ts` instantiated webview services directly via `new GrailsDashboard()`, `new DependencyGraphService()`, and `new GormSqlPreviewService()` instead of constructor injection via `ServiceContainer`.
- Failure/missing behavior and smallest reproducer:
  - Opening dashboard showed hardcoded "94% coverage" and "24 artifacts" regardless of workspace project content.
  - Webviews lacked CSP meta tags, permitting unrestricted script execution if malicious content was injected.
  - Screen-reader users could not inspect nodes in the SVG dependency graph; keyboard-only users could not focus or navigate nodes.
  - High-contrast mode rendered unreadable low-contrast text due to hardcoded light colors (`#ffffff`, `#d1d9e6`).
- Relevant invariant IDs and affected owner/reader/cache boundaries:
  - `INV-OWN-003`: Commands have zero logic, delegate to UseCases/Services; services registered only in `ServiceContainer`.
  - `INV-OWN-004`: Webview panels owned by designated services, disposed on panel close or service dispose.
  - `INV-DISC-003`: Views/tools show actual model state, origins, and stale/partial/error states; static SQL approximation is labeled accurately.
  - `INV-PERF-001`: Views do not start heavy work on activation merely to look populated.
  - `INV-PERF-002`: Large results use filters/paging/lazy layout and bounded messages.

## Implementation decision

- Intended observable result; non-goals:
  - **Dashboard (`DashboardService.ts`)**:
    - Unified into single service, registered in `ServiceContainer`, constructor injection (`INV-OWN-003`).
    - Disclose origins: "Origin: Workspace Project Discovery", "Origin: Subsystem Lifecycle State".
    - Display actual project model state (project names, root paths, resolved dependencies count).
    - Handle empty state cleanly ("No Grails Projects Detected" + Discover Projects button).
    - Display degraded state when language server is disconnected ("Language Server Disconnected").
    - Eliminate all fabricated metrics ("94%", "1.2s", "24 Artifacts").
    - Strict Content-Security-Policy with nonce and zero inline handlers.
    - Keyboard accessibility (`tabindex="0"`, `role="article"`, `:focus-visible`, Windows High Contrast support).
  - **Dependency Graph (`DependencyGraphService.ts`)**:
    - Disclose origin: "Origin: Resolved Gradle Classpath (via LSP)".
    - Provide configuration selector (`compileClasspath`, `runtimeClasspath`, `testCompileClasspath`).
    - Cap rendering at `MAX_RENDER_NODES = 250` with node count badge.
    - Provide live search/filter input (`#filterInput`).
    - Provide switchable Accessible Table View (`role="table"`, `<th scope="col">`) for keyboard and screen-reader users.
    - Respect `@media (prefers-reduced-motion: reduce)`.
    - Strict CSP with nonce and zero inline handlers.
  - **GORM SQL Preview (`GormSqlPreviewService.ts`)**:
    - Accurately labeled: "Static DDL Approximation" with explicit notice: "simulated DDL and is not executed against a live database".
    - Disclose origin: "Origin: Static Domain AST Analysis".
    - Provide accessible pre region (`tabindex="0"`, `role="region"`, `aria-label="SQL DDL Output"`).
    - Provide accessible "Copy SQL" button.
    - Strict CSP with nonce and zero inline handlers.
  - **Service Container & Command wiring**:
    - Update `ServiceContainer.ts`, `UICommands.ts`, `GrailsTaskCommands.ts`, and deprecate `GrailsDashboard.ts`.
    - 7 comprehensive unit tests in `viewsAndAccessibility.unit.test.ts`.

Implemented project-based rendering, empty states, lifecycle status badges, strict CSP with nonces, and accessible keyboard focus.
  - **DependencyGraphService**: Implemented `client/src/features/dependency-graph/DependencyGraphService.ts` with resolved Gradle classpath origin disclosure, configuration selector, `#statusBanner` container, `#filterInput` filtering, `MAX_RENDER_NODES` bounding, accessible `#table-view` table mode, and reduced-motion styling.
  - **GormSqlPreviewService**: Implemented `client/src/features/gorm-sql-preview/GormSqlPreviewService.ts` with static DDL approximation labeling, AST origin disclosure, keyboard-focusable pre block, clipboard copy button, and CSP nonce protection.
  - **WebviewStateManager**: Exported `getNonce()` and `getWebviewCsp()`.
  - **UICommands & ServiceContainer**: Delegated `grails.showDashboard` to container; deprecated `GrailsDashboard.ts`.
  - **Unit test suite**: Created `client/src/test/viewsAndAccessibility.unit.test.ts` covering all R4-07 criteria.
